# Industrial Wallpaper

AI-generated desktop wallpapers of fictional industrial spaces.

## Control Room: Unit 2

A fictional 1980s nuclear plant main control room, retrofitted in a cyberpunk style. It has analog boards with a few brass details, a large panel display showing a two-loop PWR mimic, a core flux map, a reactor-vessel hologram, a video meeting panel, and procedure binders on the console.

| File | Size | Use |
|---|---|---|
| `control-room/control_room_wide_16x10.jpg` | 5504 × 3440 | MacBook displays (16:10) |
| `control-room/control_room_wide_16x9.jpg` | 5504 × 3072 | 16:9 monitors |

Made with Google's Nano Banana Pro (Gemini 3 Pro Image) through OpenRouter, with deterministic touch-ups in Python. Freely licensed Wikimedia Commons photos of real control rooms were used only as style references.

To set one on macOS, go to System Settings → Wallpaper → Add Photo…, then choose Fill Screen.
